# AI 生图素材规范

本规范用于快手互动作品 AI 生图时的图片尺寸、分辨率、色彩模式和文件格式要求。

## 尺寸要求

根据素材用途选择合适的图片尺寸：

| 素材类型 | 建议尺寸上限 |
|---|---|
| 小图标、道具、按钮图标 | 128×128 或 256×256 |
| 普通角色、怪物、建筑 | 不超过 512×512 |
| 大型角色立绘、局部特写 | 不超过 1024×1024 |
| 全屏背景 | 按目标作品分辨率制作；竖屏通常为 1080×1920，横屏通常为 1920×1080 |
| 长背景、地图 | 切片处理，不直接提交一张超长 4K/8K 图片 |
| 单张纹理 | 不超过 2048×2048 |

如果素材需要适配多个用途，按其中要求最高的目标尺寸生成；不要为了通用而默认生成超大图片。

## 文件要求

- 分辨率：建议 72 PPI。
- 色彩模式：RGB。
- 文件格式：优先使用 PNG 或 JPG。
- 需要透明背景时使用 PNG；不需要透明背景且更关注文件体积时可使用 JPG。
- 导入项目资源前检查图片实际像素尺寸、色彩模式和文件格式，不要只依据文件名或生成参数判断。

## 生成流程要求

1. 先确认素材用途、目标画面方向（竖屏或横屏）和项目目标分辨率。
2. 按用途选择合适的尺寸，不得直接使用超过需求的 4K/8K 图片作为普通素材。
3. 长背景或地图拆分成多个切片后再导入。
4. 生成后检查像素尺寸、RGB 色彩模式和文件格式。
5. 将处理后的素材放入项目约定的资源目录，并遵守项目自身的命名和目录规范。

本规范是推荐的 AI 生图尺寸与格式基线；如果平台审核规则、项目技术方案或具体素材用途有更严格要求，以更严格要求为准。
